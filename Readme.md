

# LoginAndSignup-FrontEnd

Este projeto é uma interface de autenticação (login e cadastro) desenvolvida com foco em simplicidade e boa experiência do usuário.

## ✨ Sobre o projeto

A aplicação consiste em duas telas principais:
- **Tela de Login**
- **Tela de Cadastro**

Ambas foram construídas com HTML, CSS e JavaScript puro, seguindo boas práticas de estruturação e estilização. O design foi inspirado e adaptado a partir de um protótipo criado no [Figma](https://www.figma.com/design/gHWZv34dgAWl9l0c7IP8iz/Login-and-Sign-Up-with-Animated-Prototype--Community-?node-id=0-1&t=RBmLh2DMP6rHpZki-1), garantindo uma aparência moderna e funcional.

## 🎨 Design

O layout foi baseado em um protótipo desenvolvido no Figma, com atenção especial à:
- Tipografia clara e legível
- Paleta de cores suave e profissional
- Componentes reutilizáveis e responsivos

## 🚀 Tecnologias utilizadas

- **HTML** – estrutura da aplicação
- **CSS** – estilização e responsividade
- **JavaScript** – interatividade e validação básica
